# Ride Sharing System

## Description
A Python OOP mini project demonstrating:
- Abstract Classes
- Inheritance
- Polymorphism
- Encapsulation
- Property Decorators
- Custom Exceptions
- File Handling
- Decorators

## Project Structure

Ride_Sharing_System/
├── main.py
├── vehicles.py
├── decorators.py
├── exceptions.py
└── ride_history.txt

## How to Run

```bash
python main.py
```
